## 2. 무엇을 만드나 — 감지 → 판단 → 알림 (p.2)

작업 현장의 위험 상황을 **엣지 기기(라즈베리파이)가 스스로** 감지하고 판단해, 즉시 알림까지 처리하는 시스템.

| 단계 | OT 설명 | 우리 프로젝트 |
|---|---|---|
| DETECT 현장 위험 감지 | 카메라·센서로 작업자 접근, 객체, 위험 구역 침입 등을 실시간 인식 | 열화상 동적 위험 ROI, 사람 인식, 가스 |
| JUDGE 이벤트 판단 | 위험 여부 판단 로직, **오탐을 줄이는 기준** | 정상·주의·경보·대피 4단계 ([02](02-state-machine.md)), 설정값 ([config.yaml](../config.yaml)) |
| ALERT 안전 알림 | LED·음성·통신 경보, **감지부터 알림까지 하나의 파이프라인** | 부저 주기·LED 색·출구 LED·스피커 안내 ([02](02-state-machine.md) 4번) |

## 9. 소스코드와 시연영상 (p.12)

**소스코드**
1. 프로젝트 전체 Repository를 압축해 제출
2. 여러 Repository면 하나의 제출 파일로 구성
3. **MCU · 라즈베리파이 · 모델 학습 코드 모두 포함**
4. 최종 제출본은 **압축 해제 후 실행·구성을 다시 점검**

**시연영상**
- **5~10분, 100MB 이하.** 발표 영상이 아니라 **기능 시연** 영상
- 영상에서 보여 줄 것 (예시): 실제 장비(하드웨어) 구동 · 위험 상황 연출 및 감지 · 카메라·센서 입력 확인 · 판단 결과·경보 동작 · 추론 속도·정확도 확인 · **기능별 소개 음성 포함**
