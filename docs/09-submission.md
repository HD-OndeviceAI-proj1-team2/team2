## 2. 소스코드 제출 점검 (OT p.12)

- [ ] `main` 브랜치 최신 상태를 압축했다 (dev 아님)
- [ ] 라즈베리파이 코드(`main.py`, `config.yaml`, `core/` `sensors/` `vision/` `decision/` `actuators/` `logging_/`), **MCU 코드(사용 시)**, **모델 학습 코드**가 모두 들어 있다
  - ⚠️ 학습 코드를 둘 폴더는 아직 정하지 않았습니다. 정해지면 이 줄에 위치를 적어 주세요.
- [ ] 모델 파일처럼 깃에서 뺀 파일 중 실행에 꼭 필요한 것은 받는 방법을 [models/readme.md](../models/readme.md)에 적었다 (`logs/`는 실행하면 새로 생기므로 제출하지 않아도 됨)
- [ ] **압축을 새 폴더에 풀고** README대로 실행해서 동작을 확인했다
- [ ] 비밀번호·토큰 같은 비밀 정보가 없다

## 3. 시연영상 점검 (OT p.12)

- [ ] 5~10분, 100MB 이하
- [ ] 발표 영상이 아니라 **기능 시연** 영상이다
- [ ] 실제 장비(하드웨어)가 동작하는 장면
- [ ] 위험 상황 연출 → 감지 장면 (히터 스위치 ON → 위험 ROI 생성)
- [ ] 카메라·센서 입력 화면
- [ ] 판단 결과·경보 동작 (단계별 부저·LED, 출구 LED, 작업자 접근 안내 방송, 경보 중 불·연기 → 대피 안내 방송)
- [ ] 관제 센터 로그 화면 (단계별 사유·당시 데이터, 센서 하나를 뽑았을 때 고장 로그)
- [ ] 추론 속도·정확도 확인 장면 ([07](07-performance.md) 숫자)
- [ ] **기능별 소개 음성**
