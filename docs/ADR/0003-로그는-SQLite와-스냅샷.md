# ADR-0003: 기록은 SQLite DB와 경보 순간 스냅샷으로 남긴다

- 상태: 확정 (2026-11-25 팀 결정 — 코드 뼈대 확정 시)
- 대체하는 결정: 2026-11-24 "로그는 CSV 파일 6개로 저장" (`csv_logger.py`, 03-interface v0.3)

## 배경
처음에는 메시지 종류마다 CSV 파일을 나눠 저장하기로 했다. 엑셀로 바로 열 수 있다는 장점이 있었지만, 경보 하나가 시작되고 끝날 때까지의 흐름(사고 하나)을 보려면 여러 파일을 `seq`로 다시 합쳐야 했다. 또 경보 순간 현장이 어땠는지 보여 줄 사진이 없었다.

## 결정
- 경보 이벤트·평상시 온도는 **SQLite DB 파일 하나**(`logs/*.db`)에 테이블로 저장한다.
- 경보 단계가 바뀌는 순간의 일반 카메라 영상을 **스냅샷 이미지**(`logs/snapshots/`)로 남긴다.
- 사람이 볼 사고 리포트는 `EventLogger.exportIncidentReport()`로 **CSV로 내보낸다**.

## 결과
- 좋은 점: 사고 하나(정상 → 경보 → 정상)를 테이블 조회 한 번으로 볼 수 있다. 파이썬 기본 라이브러리(`sqlite3`)라 설치가 필요 없고, 라즈베리파이에서 인터넷 없이 동작한다. 스냅샷은 결과보고서·시연 영상의 근거 자료가 된다.
- 주의할 점: DB 파일은 엑셀로 바로 열리지 않아서 CSV 내보내기가 필요하다. 전원이 갑자기 끊겨도 기록이 남으려면 이벤트마다 `commit`해야 한다 (REQ-012, FMEA F-20). 스냅샷이 쌓이면 용량이 커지므로 `logs/`는 깃에 올리지 않는다.
- 테이블 구조는 [03-interface](../03-interface.md) 5번에 있다.
