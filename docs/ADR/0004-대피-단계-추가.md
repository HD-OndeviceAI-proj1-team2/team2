# ADR-0004: 경보 위에 대피 단계를 추가한다 (경보 + 불·연기 감지)

- 상태: 확정 (2026-11-25 기획안 수정)
- 바꾸는 결정: [ADR-0002](0002-경보-3단계와-판단-기준.md)의 "3단계" 부분. ADR-0002의 주의·경보 조건은 그대로 유지

## 배경
ADR-0002에서는 경보 단계에서 바로 대피 안내 방송을 했다. 그런데 경보 조건(100℃ 10초, 130℃, 가스 2배, 주의 1분 지속)은 **불이 나기 전**의 위험 신호여서, 경보마다 전원 대피를 안내하면 대피가 너무 자주 일어나고 작업자가 경보를 무시하게 될 수 있다. 실제로 불·연기가 보일 때를 구분해 "지금 나가야 한다"를 따로 알릴 필요가 있었다.

## 결정
- 단계는 **정상(NORMAL) · 주의(CAUTION) · 경보(ALARM) · 대피(EVACUATE)** 4개로 한다.
- **대피 조건:** 경보 단계에서 일반 카메라가 불이나 연기를 감지했을 때.
- 대피 안내 방송은 **대피 단계**에서 한다. 경보 단계에서는 위험 구역 1.5배 범위에 들어온 작업자에게만 안내 방송을 한다.
- 경보·대피는 리셋 버튼을 누를 때까지 유지(래칭)하고, 누르면 주의로 돌아간다.
- 경보·대피 단계 모두 출구 LED로 위험 구역을 피하는 출구를 안내한다.
- 불·연기 인식은 **선택 기능(플러스 알파)에서 필수 기능으로 바뀐다** (REQ-026).

## 결과
- 좋은 점: 불이 나기 전(경보)과 불이 난 뒤(대피)를 나눠 알릴 수 있다. 불·연기 감지는 이미 경보인 상황에서만 단계를 올리므로, 불·연기 오검출 하나만으로 대피가 울리지 않는다.
- 주의할 점: 불·연기 학습 데이터 확보와 라즈베리파이 처리 속도가 일정에 부담이 된다. 시연에서는 실제 불꽃·연기를 쓰지 않으므로(C-04), 불·연기를 어떻게 보여 줄지(사진·화면 등) 정해야 한다. 경보와 대피의 LED·부저가 같으면 소리·빛만으로는 두 단계를 구분할 수 없다 ([02-state-machine](../02-state-machine.md) 7번).
