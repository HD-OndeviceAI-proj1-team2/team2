[구현 현장 상황: 배터리 공장을 지켜보는 CCTV+열화상 카메라]


* 주제 : 배터리 공장에서 위험 상황 혹은 화재 시 경보를 울려 대피시킨다
* 시연 방법 : 작은 배터리 공장 한 방을 만들어 한 방향에서 CCTV+열화상 카메라로 위험을 감지 
* 필요 물품 : 라즈베리파이용 일반 카메라/열화상 카메라 각 1대, 가스검출기, LED 다량, 공장 재현 피규어, 사람 피규어, 발열패드


1. 비전1 - 일반 카메라(사람 모양 학습 메인)
-> 사람 모형 학습 (위험 구역 ROI와 비교할 때 필요)
(아래는 플러스 알파-라즈베리파이의 사양 및 프로젝트 기간 여유가 있다면 생각)
-> 불 모양 학습 (플러스 알파)(열감지까지 더해지면 정확도 올릴 수 있겠다) (불 데이터 찾기)
-> 연기도 학습 가능 (연기 데이터 찾기)


2. 비전2 - 열화상 카메라(열 감지된 구역 찾기)
-> 특정 구역을 위험 구역(ROI)로 만들어줌


3. 알리는 방법
-> 부저+LED
-> 경보음 수준은 부저 주기가 다르게(위급할수록 빠른 주기)


4. 대처
-> 부분적으로 불을 진화하거나 격리
-> 위험 구역(ROI)판단 하에 안전한 대피로 LED 안내
