# training — 모델 학습 · 경량화

**역할:** 사람 인식 모델을 학습하고, 라즈베리파이에서 돌 수 있게 변환·경량화(양자화)하는 코드를 둡니다. **OT 가이드 p.12: 제출 소스코드에 학습 코드 포함 필수.**
**주 담당:** SW/AI

## 여기에 넣는 것
- 학습 노트북·스크립트, 데이터셋 설정 파일(라벨 목록, 경로)
- 모델 변환·양자화 스크립트, 변환 전후 비교 결과 요약 → 결과 숫자는 `docs/07-performance.md`에 기록

## 넣지 않는 것
- 학습용 이미지·라벨 원본 → Drive (용량)
- 학습된 가중치 파일 → `models/` (깃 제외)
